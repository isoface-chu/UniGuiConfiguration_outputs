# mtListEditor 宿主回归清单

## 0. 测试前准备

1. **只测最新包**：`deployment/list-editor-import-20260922/UniGuiConfiguration.dll`，SHA-256 `D0676D0B24673E1AD88E7F439A60B9EEB4876F51466534E2ABAA80DCB138A78E`。
   该包 2026-09-25 重建，是此前各包的累积结果；`START_HERE.md` 里写的 `5A421B1C…` 是重建前的旧哈希，以包内 README 为准。
   （mtMasterSlave 的项目 §C 用 `masterslave-record-layout-20260922` 之后的同一累积版本即可，无需另换包。）
2. 更新步骤：退出宿主并确认进程消失 → 备份现有 `UniGuiConfiguration.dll` → 替换 → 重启宿主。
3. **换 DLL 不会改变已生成的模块脚本**：每个要测的模块都要在精灵里重新点一次"完成"。
4. 测试库用测试数据，不要用生产业务表。
5. 每项结果记 通过 / 失败 / 未测；失败请附截图或提示原文。

建议准备两套测试配置：
- **配置 A（单表）**：一张主表，主键 MaxInt 或 Guid，不配从表。
- **配置 B（主从）**：主表 + 一张从表（配关联字段/关联从表；记录编号、明细编号、从表唯一、从表非空都配上）。

## G. 本清单不覆盖（仍未做 / 未测）

- 从别的模块或查询窗体多选记录后导入当前列表（需要 list editor 的模态桥，单独立项）。
- 复杂多表写入、真实并发、Oracle 等更广泛数据库方言、`SeqUence`。
- 主键为"数据库自增"的主从写入（被明确拒绝，不是缺陷）。
- 明细里的查找 / 多列下拉字段（会被明确拒绝）。
- 宿主侧真实权限拒绝与落库、大数据量。
